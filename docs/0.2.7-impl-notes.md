# Delta Harness 0.2.7 implementation notes

## 4. Resilience trio

- Files: `src/provider.ts`, `src/run.ts`, `test/resilience-027.test.ts`.
- Output-capped tool batches now checkpoint synthetic `done` journal/tool rows atomically and never execute, including after resume.
- Responses incomplete reasons feed `finishReason`; invalid/truncated model arguments have non-breaker tool classes.
- `parseToolArgs` performs one 64K-bounded control/trailing-comma repair and accepts only non-array objects.
- One `providerErrorClass` now controls retries/failover and both retry/terminal telemetry.
- Deviation: none.

## 5. Safe-mode boot + self revert

- Files: `src/config.ts`, `src/index.ts`, `src/run.ts`, `src/queue.ts`, `src/self.ts`, `test/safe-mode.test.ts`.
- `DELTA_SAFE_MODE=1` selects the cloned safe floor, primary provider/model only, neutral vocab, no MCP/skills/hydration/reflection/self-write, and no workspace prompt layers.
- Refresh/MCP boot is explicitly guarded; startup logs `SAFE MODE`; per-run metadata/env cannot expand it.
- Existing authenticated Cockpit revision/revert endpoints remain the sole revert implementation.
- Deviation: no CLI was added because the existing HTTP surface is already the designed lean path.

## 6. Local skills backend (use-only)

- Files: `src/adapters.ts`, `src/local-skills.ts`, `src/retrieval.ts`, `src/reflect.ts`, `src/promote.ts`, `src/skill-registry.ts`, `src/config.ts`, `src/index.ts`, `src/run.ts`, `test/local-skills.test.ts`, `test/promote.test.ts`.
- `DELTA_SKILLS=mcp|local|off` defaults to byte-compatible MCP behavior; local/off remove known registry MCP tools.
- Local discovery is boot-loaded, metadata-only, bounded, direct-child-only, symlink/traversal rejecting, and exposes no `propose`.
- Local prompt retrieval emits metadata plus a `read_file` path; off removes run/reflection skill prose.
- Capability promotion is staged/claimed only when `propose` exists.
- Deviation: the adapter lives in `src/local-skills.ts` because it exceeds one screen, as the design allows.
