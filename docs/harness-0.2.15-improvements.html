How to read the numbers. The red figures are measured — recomputed from the Aperture lane databases, Ferni's live database, and the Delos field report, not quoted from memory. The improvements are by construction: each defect's firing condition was removed and locked by a test that failed on the old code, then verified live on a from-source deploy. The two that were losing money — correctness and output

D-1 · COMPACTION

The agent now stays on your question after compaction

When a long session ran out of context, the engine compressed the history and pinned "the task" at the top of the summary as trusted instructions. It pinned the first request the session ever saw — not the one being worked on. On any session with more than one request, the agent was re-instructed to do old work.

Measured42 of 42 exposed compactions pinned a different task than the live one, across three lanes (27 on the paid client lane, 13 on Ferni). On the busiest lane, 23 of 27 stale pins were longer than the real request — a big old instruction outranking a short live one. Delos watched an agent answer a 40-minute-old question twice, with no error anywhere.
NowThe pin is read from the compacting run's own request, bound by both run and session id, and the fallback that was the bug is deleted — the compiler proves no caller can reach it. On the paid lane's shape (23 of 71 sessions hold more than one run; the longest holds 19) this defect simply cannot fire again.
D-9 · EXHAUSTION

A run that hits its budget hands you its work, not an apology

A budget-exhausted run had its results sitting on disk — spilled tool outputs, research files, the agent's own plan — and returned none of it. The user got one sentence of internal counters, wrapped by the chat layer in "try again in a moment", which reproduces the failure and bills again.

MeasuredOn two Aperture lanes: 11 runs, 771 tool calls, $140.98 and 158 minutes of paid work destroyed — each run returning literally budget exhausted: 295 calls…. Delos's worst case: 66 steps, 379 calls, 33 minutes, 26 spill files and 13 research directories on disk — zero bytes of it offered.
NowThe reply carries the plan at the moment it stopped, every spill and research file this run produced (enumerated from disk under the run's own ID — nothing stale, nothing forged), and advice to narrow instead of retry. The counters still exist — in runs.error and telemetry, where operators look. Verified live: a real over-budget run returned its plan and both artifact paths.

D-12 · PROVIDER

Sub-agents work on the OpenAI backend — the demo path is unblocked

MeasuredThe ChatGPT/Codex backend rejects max_output_tokens at any value. Parent turns never send it, so the connection worked for the parent while 24 of 24 sub-agent calls on one observed run 400'd — each attempt billed, the whole delegation surface dead, and no config setting could show why.
NowThe parameter is suppressed for that one host (wire-proofed denylist; every other endpoint keeps its cap). This is the prerequisite for ferni-codex-sol and the gpt-5.6-sol demo route. Final gate: Delos's live 3/3-children check.

Seeing what was invisible — the gaps that let the above hide

D-3 · STATUS

A tool that can't work is no longer silently offered

The tool allowlist was a ceiling, not a guarantee: registration preconditions failed silently. Delos configured 16 tools and had 13 — and nothing, anywhere, said so. When a tool errors, the model doesn't stop; it routes around it, expensively.

MeasuredOne Telegram question with no search key: the agent brute-forced raw HTML instead — 74 tool calls, 724,804 input tokens, wrong answer. The same question with the key: 37 calls, 350k tokens, right answer. One absent env var ≈ 2× the cost and the correctness.
Now/v1/status reports three states with reasons — registered, unusable now (heals the moment a credential lands, no restart), omitted (fix config, restart) — plus one loud boot line. First live boot on Ferni it immediately exposed a real, previously invisible hole: codex was never installed in the image, so the code tool had been silently missing all along.
ferni boot · delta: 18 tools registered. Omitted: code (CLI 'codex' not found or not executable on this host)
A-4a · MEMORY

Memory-save refusals tell the agent exactly how to fix them

Measured86 of 240 fleet remember calls were refused for size — with no overage number and no current file. The agent shrank by guesswork, re-fired, failed again, and hit the three-strike breaker: the single largest self-learning failure on the Aperture lanes. Lanes silently stopped learning.
NowThe refusal says exactly how many bytes over, and hands back the current on-disk file as a merge base — one informed retry instead of three blind ones. Ferni's self-file is at 79% of its cap right now; this lands just in time.
A-1 · COMPACTION

Load-bearing identifiers survive compression

MeasuredThe summary audit retries once, then ships lossy by design. Measured on the fleet: 18–34% of load-bearing identifiers (IDs, counts, paths, years) missing from committed summaries; worst cases lost 30 of 30. For a recruiting product, that's candidate identity evaporating mid-task.
NowWhatever the model drops, a machine-built appendix carries verbatim — bounded, and reserved inside the summary's size cap so it can never bloat the context it protects. The accuracy floor is no longer "whatever the summarizer felt like keeping".
A-2 · TELEMETRY

Rejected tool calls are finally countable

Measured9.4% of one lane's tool calls were "unknown tool" rejections that no counter recorded — the model routes around them and the money is spent before anyone can notice a pattern.
NowEvery rejection emits tool.rejected with a closed reason (unknown / not_allowed / breaker_disabled). The raw model-invented name stays on-box unless payload capture is on. This is the data the 0.2.16 auto-activate decision waits for.

Hygiene & safety — what should never have been possible

D-8 · SECURITY

The delegated CLI can no longer reach the operator's accounts

DemonstratedA delegated codex session, asked to prove its Gmail skill was inert, listed the operator's real inbox — 6,913 messages, write scope. Nothing on the host granted it: the connector lives server-side on the CLI's own login. An agent with no send-capable tool could have sent mail as its owner in one hop.
NowConnectors are disabled by default (--disable apps --disable plugins, verified end-to-end on the pinned CLI). Operators who deliberately want a connector set the command explicitly — and their setting is used verbatim, never modified.
D-7 · SCRATCH

Engine scratch moves off your documents

Three families of per-run intermediate state — spilled tool outputs, research artifacts, the model's scratchpad — were written into the agent's workspace. Fine for a throwaway checkout; on Delos's git-tracked, phone-synced document vault it meant raw untrusted web fetches committed to git and delivered to the operator's phone, and engine output landing in the same folder namespace as human research notes.

MeasuredResearch trees reached Delos's git twice. Their workaround — a bare research/ gitignore rule — was itself a footgun that silently swallowed new files in 5 legitimate vault folders. The default said nothing about any of this.
NowDELTA_SCRATCH_DIR (Fly deploys default to /data/scratch), research renamed under hidden .delta/research/ so no one needs an ignore rule, per-run scratchpad wiped as before. The two hazards the review caught are closed: legacy artifacts still demote (no silent context-bloat regression), and the model can still read everything the engine points it at.
D-4 + D-5 · SKILLS

Skills stay findable — and stay current without restarts

MeasuredTwo Delos skills were unreachable for months: a YAML block-scalar description parsed to nothing, so the skill registered but search could never surface it — and the identical file works fine on a laptop, which is why nobody noticed. Separately, the skill index was built once at boot; Delos ran a 2-minute external restart timer just to pick up skill edits.
NowBlock-scalar descriptions parse (no YAML dependency added); a too-short description warns loudly. The index re-scans behind a cheap per-file stat, so added, renamed, and re-described skills appear without a restart. Delos deletes the restart timer.
D-11 · BUDGET

Plus one small knob

DELTA_MAX_STEPS completes the third budget axis (steps, alongside tokens and cost) for deep-research workloads. Honest scope note: the fleet's binding constraint is tokens — max observed steps is 62 of 100 — so nobody currently deployed will see a change.
