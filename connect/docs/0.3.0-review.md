## P2

- `connect/src/telegram.ts:224` — `resolveDocumentPath` validates a pathname, but `Bun.file` reopens it lazily, so a workspace writer can swap the checked file/ancestor for a symlink before upload and escape confinement. Fix: open the workspace-relative target with beneath/no-follow semantics and upload an already-open fd/blob snapshot instead of a lazy path-backed file.
- `connect/src/supervisor.ts:109` — after one normal-plus-safe boot sequence fails, `this.failures` stays at `maxFailures`, so every later wake or `/restart` skips normal mode forever. Fix: scope/reset the normal-attempt counter for each `bootWithFallback` sequence.

## P3

- `connect/src/telegram.ts:230` — appending `Bun.file(resolved.path)` without an explicit filename sends the canonical absolute server path as the multipart filename. Fix: pass a sanitized `basename(relativePath)` as the third `FormData.append` argument.
- `connect/src/supervisor.ts:85` — `restart` calls `stopChild`, then `bootOnce` immediately calls it again. Fix: remove the outer `stopChild` and keep process replacement centralized in `bootOnce`.

No material finding in the loopback-plus-token control gate, operator-command authorization, or Markdown escaping/tag balance.
